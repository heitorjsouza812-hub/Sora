# 2026-10-17 — Peças do Rakazo portadas para o backend

**Quem:** Heitor (com o Claude).

## O que foi feito

O Heitor pediu para analisar o [Rakazo](https://github.com/elie222/rakazo) (agente open source em TypeScript, Apache 2.0, que mira o mesmo espaço da Sora) e trazer para o projeto tudo o que desse, inclusive as fases 2 e 3, com commit direto na `main`.

Como a Sora é Python/LangChain, as peças foram **portadas** (não copiadas), com nomes em PT-BR, encaixadas nos módulos que já existiam e com testes. O mapa completo, a licença e o que ficou de fora estão em [`docs/referencias/rakazo.md`](../docs/referencias/rakazo.md).

- **Fase 1:** limite de 6 saltos entre agentes, catálogo preguiçoso de ferramentas (mais de 20 viram 3 meta-ferramentas), política de aprovação por ferramenta, juiz do revisor com falha fechada, compactação do histórico (janela 50 + resumo), `buscar_historico`/`ler_historico`, `catalogo_tarefas`, `propor_instrucoes`, cláusulas de uso das ferramentas, redação de segredos e rótulos do painel Trabalho. Implementados também os stubs `carregar_prompt`, `preencher`, `cercar`, `rotulo_do_passo`, `parametros_sem_segredos` e `exige_revisao`.
- **Fase 2:** memória (`lembrar`, `buscar_memoria`, `esquecer_memoria`), `enviar_para_agente`, agenda com cron no fuso do usuário e resposta silenciosa (`SEM_RESPOSTA`), pendências, habilidades SKILL.md e detector de trabalho parado.
- **Fase 3:** conectores MCP via `langchain-mcp-adapters` (com SSRF, cabeçalhos cifrados e catálogo preguiçoso), canal Telegram (webhook + vínculo por código + rotas em `/v1/canais`), voz (OpenAI, ElevenLabs, Cartesia, Fish Audio), navegador por texto (Playwright opcional), `executar_comando` em contêiner Docker descartável, `gerar_grafico` e busca DuckDuckGo só para desenvolvimento.
- **Banco:** migração `0004_pecas_do_rakazo` (colunas em `conversas` e `mensagens`; tabelas `rotinas`, `pendencias`, `habilidades`, `conectores`, `canais_vinculados`).
- **Dependências novas:** `croniter`, `langchain-mcp-adapters`, `matplotlib`; grupo opcional `navegador` com `playwright`.

## Verificação

- `uv run ruff check .` e `uv run ruff format --check .` limpos.
- `uv run pytest`: suíte inteira verde (os testes de integração pulam sem Docker, como antes). Os testes novos estão em `backend/tests/unitarios/test_rakazo_fase{1,2,3}.py`.
- O teste do navegador de verdade pula sem o Chromium do Playwright (`playwright install chromium`).
